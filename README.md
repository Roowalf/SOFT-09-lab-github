# Práctica 2 de Git y GitHub

Repositorio de laboratorio del curso SOFT-09.

Objetivo: practicar el control de versiones con Git.

## Actividades

- Registrar cambios con commits y sincronizar el repositorio con GitHub.
- Proponer una modificación del README desde una rama y revisarla mediante un Pull Request.
- Resolver un conflicto al editar la misma línea en dos ramas.
- Ejecutar un flujo básico de GitHub Actions.
